## 🚀 Cómo correrlo en local

1. Cloná el repositorio:
```bash
   git clone https://nahuelvarelautn.github.io/mi-portfolio/
```
2. Abrí la carpeta y hacé doble clic en `index.html`.

No requiere instalar nada.
